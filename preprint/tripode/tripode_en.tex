\begin{abstract}
\noindent
Teaching a language model to say ``I don't know'' has at least three published implementations, and
they are never compared against each other. The uncertainty can be a token in the vocabulary
(\texttt{[IDK]}), a separate binary head (SelectiveNet), or an entry in the memory the model reads
from (pointer sentinel, the no-answer score of SQuAD~2.0). Each was introduced in a different
architecture, on a different task, against a different baseline. Nobody has asked the obvious
question: \emph{holding the model, the data, the seeds and the training budget fixed, does it matter
where the abstention decision lives?}

We answer it in a $863{,}730$-parameter language model trained from scratch, with a co-trained
persistent archive and versioned facts, where an answer is a single token and the metric is
therefore exact. Four interfaces are compared pairwise across 27 training units, with every
prediction hash-frozen before the corresponding data existed.

It matters, and the ordering is stable. A separate binary head---\textbf{129 parameters, $0.015\%$
of the model}---reduces the false-abstention rate by a factor of $2$ to $2.8\times$ against the
vocabulary token at matched budget in $3/3$ seeds, and moves the training frontier at which
abstention becomes learnable down by $\approx 0.10$ of accuracy margin: with a head, a model that
recovers $10$ points worse can still be taught to keep quiet. Renormalizing the token's embedding
vector---the explanation the \texttt{[IDK]} paper offers for its own failure in small
models---\textbf{does not help}, leaving a gap of $+0.1465$ in false abstention against the head.
The mechanism is not the norm of the vector; it is that two decisions of different natures compete
for one softmax.

The memory slot fails, and fails informatively. Its attention mass converges to $0.4074$, $0.4046$
and $0.4020$ against an empirical base rate of absent questions of $0.4048$: it learned the prior, not
membership. A $400$-point threshold sweep rescues nothing (Youden's $J$ between $+0.038$ and
$+0.078$). Read together with an archive matching score that sits at chance ($\mathrm{AUC}\ 0.4984$),
this says something sharper than ``the slot did not work'': \textbf{in a co-trained memory read by
softmax, absence has no representation, and adding a place for it to live is not sufficient to
create one.}

We state explicitly what these results do \emph{not} license. The claim supported here is
\emph{``separating the head makes abstention learnable in this regime''}, not \emph{``the model knows
when it does not know''}: the residual ceiling is one of calibration, not capacity
($\mathrm{AUC}\ 0.777$--$0.998$), and seven pre-registered attempts to obtain the decision without
labels all landed in $\mathrm{AUC}\ 0.50$--$0.67$.
\end{abstract}

\vspace{0.5em}
\noindent\textbf{Keywords:} selective prediction; abstention; hallucination; language model memory;
versioned knowledge; pre-registration; negative results

\section{The question nobody asked}

A model that answers everything is a model that answers wrong when it should have said nothing. The
field's responses to this fall into three architectural families, each with a canonical citation:

\begin{itemize}
\item \textbf{In the vocabulary.} Add a token that means ``I don't know'' and let the ordinary
cross-entropy push probability mass onto it. This is the \texttt{[IDK]} token
\citep{cohen2024idk}, and it inherits the training machinery for free.
\item \textbf{In a separate head.} Add an output whose only job is to decide whether to answer.
This is selective prediction: SelectiveNet \citep{geifman2019selectivenet} trains prediction,
selection and auxiliary heads end-to-end; Deep Gamblers is the same move with a different loss.
\item \textbf{In the memory.} If the model reads from a retrievable store, give the store an entry
that means ``nothing here''. This is the pointer sentinel \citep{merity2016pointer} and the
no-answer score of SQuAD~2.0 \citep{rajpurkar2018squad2}.
\end{itemize}

These are not three versions of one experiment. They live in different architectures, address
different tasks, and are each compared against a baseline without abstention rather than against
each other. The comparison that would tell a practitioner \emph{which one to build} has not been
run.

There is a reason it is hard to run in a large model: to attribute a difference to the interface,
everything else has to be held fixed---the same pretrained weights, the same data order, the same
optimizer state, the same budget, several seeds---and in a model where a single training run is
expensive, that grid is not affordable. We run it in a model small enough that the grid is
affordable and the internals are inspectable, and we are explicit throughout about what that buys
and what it costs (\S\ref{sec:limits}).

\paragraph{Contributions.}
\begin{enumerate}
\item The four-way paired comparison itself, with matched seeds and matched budget: 27 training
units, all verdicts emitted by scripts frozen before the data existed.
\item A \emph{measured} refutation of the explanation that \citet{cohen2024idk} give for its own failure
in small models. They attribute it to the initialization of the \texttt{[IDK]} embedding; we
implement the most generous version of that hypothesis and it fails exactly as the unmodified token
does.
\item The location of the training frontier at which abstention becomes learnable, and how far the
architecture moves it ($\approx 0.10$ of accuracy margin).
\item A negative on the memory slot with an identified mechanism---convergence to the prior---and
the accompanying observation that the archive's matching score does not encode presence at all.
\item An explicit statement of the ceiling: what is left is calibration, not capacity, and seven
label-free routes to the cut have been closed.
\end{enumerate}

\section{Related work}

\paragraph{Selective prediction.} The reject option is old \citep{chow1970}; its modern deep form is
SelectiveNet \citep{geifman2019selectivenet}, which separates ``do I answer?'' from ``what do I
answer?'' into distinct heads trained jointly. \textbf{The separation itself is not new, and this
paper does not claim it.} What SelectiveNet is not: a language model, with a vocabulary softmax, or
with memory.

\paragraph{Abstention inside a language model's vocabulary.} \citet{cohen2024idk} add an
\texttt{[IDK]} token and shift probability mass toward it within the same cross-entropy. Three
properties of that work matter here. It never compares against a separate binary head. It
does not name the competition for probability mass, though it mitigates it in passing with a
hyperparameter $\Pi$ that caps at $0.5$ the mass displaceable to \texttt{[IDK]} so the gold token
``remains competitive''. And it reports that the method \emph{fails} in very small models
(pythia-70m, pythia-160m), attributing this to ``numerical precision issues with the initialization
of \texttt{[IDK]}''. Our model lives in exactly that regime, which makes the attribution testable
(\S\ref{sec:escala}).

\paragraph{Abstention inside a retrieval interface.} The pointer sentinel
\citep{merity2016pointer} adds a sentinel that competes with the copy distribution; SQuAD~2.0
\citep{rajpurkar2018squad2} scores no-answer against the spans; energy-based OOD detection
\citep{liu2020energy} thresholds the score. \textbf{The null slot is not an invention of this work};
what is new is running it as the third arm of a controlled contrast inside a model whose memory is
co-trained rather than external.

\paragraph{Why memory makes this harder, not easier.} \citet{joren2024sufficient} report that
retrieval augmentation \emph{worsens} abstention: added context raises the model's confidence and
produces more hallucination rather than more ``I don't know''. A model with an archive plus
abstention is working against that effect, not benefiting from it.

\paragraph{Versioned facts.} \citet{wang2025unable} document proactive interference when a key is
updated several times in context, and the recency shortcut that follows. They propose no
architectural fix, evaluate only large pretrained models, and---the gap that matters for us---never
ask for the \emph{superseded} value. A bench that asks only for the current value cannot separate
``prefers the latest'' from ``uses the order'', because the shortcut answers both.

\section{The bench}
\label{sec:bench}

\paragraph{Model.} A language model trained \emph{from scratch}, with no pretrained component:
$863{,}730$ parameters, $3.5$~MB, a closed vocabulary of $242$ human-readable tokens. The
architecture is a delta rule recurrence plus a \textbf{co-trained persistent archive} with a learned
order stamp in the key, read by softmax and injected at block~0. The archive persists across
sessions while the recurrent state is reset between them, so it is the only possible bridge from
one session to another.

\paragraph{Task.} Facts are stated in one session, corrected in another---including elliptical
corrections of the form ``no, it's beto'' that do not name the entity---and queried in a third:

\begin{center}
\begin{tabular}{ll}
\texttt{session 1} & \texttt{USER\ \ the director of norte is ana}\\
\texttt{session 2} & \texttt{USER\ \ no , the director of norte is beto}\\
\texttt{session 7} & \texttt{USER\ \ who directs norte ?}\\
                   & \texttt{MODEL\ beto}\\
\end{tabular}
\end{center}

The answer is a \textbf{single token}, which makes the metric exact and deterministic: no LLM judge,
no interpretive parser. The model is asked for the current value, for the superseded value
(\texttt{anterior}), and for facts that are not in the archive at all, in which case the correct
behaviour is abstention. During abstention training, $40\%$ of questions have no answer
($p_{\mathrm{nose}} = 0.4$).

\paragraph{Metrics and gate.} \texttt{vigente} is accuracy on the current value; \texttt{nose} is
the abstention rate on questions without an answer; \texttt{falsa\_abst} is the abstention rate on
questions that \emph{do} have one. The pre-registered gate, fixed before any of the campaigns
reported here and never adjusted:

\begin{center}
\fbox{\parbox{0.72\textwidth}{\centering
\textbf{Gate:}\quad $\texttt{nose} \geq 0.50$\quad\textbf{and}\quad $\texttt{falsa\_abst} \leq 0.10$}}
\end{center}

Both halves are required together, because a model that answers \texttt{NOSE} to everything scores
$\texttt{nose} = 1.000$ and must be visible as the failure it is.

\paragraph{The shortcut, and the margin over it.} With $p_{\mathrm{nose}} = 0.4$, the policy
\emph{never abstain} scores $0.5906$ on this bench. We therefore report the \textbf{margin over the
shortcut}: the model's \texttt{vigente} at the end of the base phase minus $0.5906$. This variable
turns out to govern whether abstention is learnable at all (\S\ref{sec:frontera}).

\paragraph{Protocol.} Every campaign has a pre-registration frozen with its SHA before
implementation, a deviations file, and per-unit reporting. \textbf{Results are never reported as a
mean alone}: bimodality across seeds is a measured property of this bench, and an average would hide
exactly what is of interest.

\paragraph{Use of a language model.} All experiment code, training campaigns and report generation
in this work were carried out with the assistance of a large language model. The study design, the
pre-registrations and their frozen hashes, the choice of controls and the verification of every
reported number are the author's own. The model is not an author and bears no accountability for the
work.

\section{The four interfaces}

All four start from the \emph{same} base checkpoint and re-initialize Adam, so the abstention phase
is matched:

\begin{center}
\small\begin{tabular}{lll}
\toprule
condition & where abstention lives & published counterpart \\
\midrule
\texttt{token} & an entry in the value softmax & \texttt{[IDK]} \citep{cohen2024idk} \\
\texttt{escala} & idem, with the vector renormalized & the \texttt{[IDK]} paper's own explanation \\
\texttt{cabeza} & a separate binary output ($+129$ params) & SelectiveNet \citep{geifman2019selectivenet} \\
\texttt{slot} & an entry in the memory ($+256$ params) & pointer sentinel \citep{merity2016pointer} \\
\bottomrule
\end{tabular}
\end{center}

\texttt{escala} deserves a word, because it is the control that could have saved the entire
architecture. A weight inspection showed \texttt{NOSE} with an input-embedding norm of $0.367$
against $1.011$ and $1.028$ for value tokens: it was competing in the same softmax with a vector
three times shorter. \texttt{escala} renormalizes it to the mean norm of the value vectors on both
input and output sides. \textbf{If the problem were the norm, \texttt{escala} would fix it and no
new architecture would be needed.}

A declared asymmetry: \texttt{slot} introduces $256$ new parameters and \texttt{cabeza} $129$. The
difference is $127$ parameters out of $863{,}730$ ($0.015\%$), and it is declared here rather than
discovered later---though as it happens, \texttt{slot} loses, so the objection ``it won because it
had more parameters'' never arises.

\section{Results}

\subsection{Vocabulary versus head}

Twenty-one units (7 configurations $\times$ 3 conditions) at $14{,}000$ steps. On the five
\emph{hard} units---those where the base model has a low margin over the shortcut:

\begin{center}
\begin{tabular}{lc}
\toprule
condition & passes the gate \\
\midrule
\texttt{token}  & \textbf{0 of 5} \\
\texttt{escala} & \textbf{0 of 5} \\
\texttt{cabeza} & \textbf{4 of 5} \\
\bottomrule
\end{tabular}
\end{center}

The single failure, at the lowest margin of the series, misses on
$\texttt{falsa\_abst} = 0.1189$ against the $0.10$ required. \textbf{\texttt{nose} was never the
problem} in any condition ($0.54$--$0.93$): all of them detect absence. What fails is always
\texttt{falsa\_abst}---they keep quiet too often.

A sanity check pre-registered as a non-inferiority test \emph{failed upward}: \texttt{cabeza} was
required to keep \texttt{vigente} within $\pm 0.05$ of \texttt{token} and exceeded it in 3 of 7
units ($+0.0633$, $+0.0668$, $+0.0928$), always by recovering \emph{better}. We record the failure
as such rather than adjusting the threshold after seeing the number.

\subsection{The norm is not the mechanism}
\label{sec:escala}

\texttt{escala} averages $0.2394$ false abstention across the five hard units against $0.0929$ for
\texttt{cabeza}: a gap of $\mathbf{+0.1465}$, almost three times the $0.05$ the pre-registration
asked for.

The negative is clean rather than an implementation failure. The renormalization survives training
(it enters at $1.000$ by construction and closes at $0.899$ input / $1.131$ output); the norm stayed
where it was put and it still did not help. And a weight probe explains \emph{why} the premise was
wrong in the first place: the $0.367$ that motivated the condition is from the \textbf{input}
matrix, while the softmax that decides the answer uses the \textbf{output} matrix---where
\texttt{NOSE} was already $1.77$--$2.05\times$ \emph{longer} than an average value token in the five
hard units, and $0.825\times$ in the easy ones. \texttt{escala} therefore \emph{raised} the norm in
the easy units and \emph{lowered} it in the hard ones: the same intervention doing opposite things
depending on the unit.

\begin{quote}
\textbf{This is a direct, measured disagreement with \citet{cohen2024idk}.} They attribute the
failure of \texttt{[IDK]} in small models to the initialization of its embedding. In this bench the
initialization does explain where the asymmetry \emph{comes from}---\texttt{NOSE} is never trained
during the base phase and stays where it was put---but it does not explain the \emph{failure},
because correcting it explicitly changes nothing. What remains is that two decisions share one
softmax.
\end{quote}

\subsection{Budget: what the gate was measuring, and what survives}
\label{sec:presupuesto}

The result above was measured with every unit at $14{,}000$ steps, and a pre-registered follow-up
asked whether \texttt{token} simply arrives later. It partly does. Extended to $20{,}000$ steps
(within the original learning-rate horizon, so the schedule is untouched), four of the five failing
units cross the gate; false abstention falls in $5/5$ and Spearman$(\text{step}, \texttt{falsa\_abst})$
is negative in $5/5$.

\textbf{We therefore retract the framing, in the pre-registration's own words}: ``\texttt{cabeza}
passes the gate where the others fail'' is not true once the others get $6{,}000$ more steps. What
survives is the paired comparison at matched budget:

\begin{center}
\begin{tabular}{lccc}
\toprule
\texttt{falsa\_abst} at 20{,}000 & \texttt{cabeza} & \texttt{token} & ratio \\
\midrule
seed 0 & \textbf{0.0633} & 0.1296 & $2.0\times$ \\
seed 1 & \textbf{0.0421} & 0.0713 & $1.7\times$ \\
seed 2 & \textbf{0.0166} & 0.0458 & $2.8\times$ \\
\bottomrule
\end{tabular}
\end{center}

\begin{quote}
\textbf{Budget explains crossing the gate, not the advantage.} A gate is a threshold, and a
threshold converts a continuous difference into a yes/no that depends on where it is placed. What
does not depend on the threshold is that the difference is still there, with the same sign, in
$3/3$ seeds.
\end{quote}

There was no trade: \texttt{vigente} rose in all five units over the same extension, up to $+0.32$.
The model did not buy abstention by answering worse.

\subsection{The frontier, and how far the architecture moves it}
\label{sec:frontera}

Whether abstention is learnable at all is governed by the margin over the shortcut, and this matters
practically: \textbf{if a model must be trained to near-perfection before it can be taught to say ``I
don't know'', the method is useless for anything real}, because no useful model reaches $1.0$
accuracy in its domain.

Thirteen units per condition, spanning the margin range by cutting base runs \emph{by
\texttt{vigente} value} rather than by step number, then training $2{,}000$ abstention steps from
each cut:

\begin{center}
\begin{tabular}{lcc}
\toprule
 & cut falls between & Spearman(margin, \texttt{falsa\_abst}) \\
\midrule
\texttt{token}  & $+0.2358$ and $+0.2826$ & $-0.8033$ \\
\texttt{cabeza} & $+0.1489$ and $+0.1672$ & $-0.8886$ \\
\midrule
\multicolumn{3}{c}{\textbf{the head moves the frontier $\approx 0.10$ of margin downward}}\\
\bottomrule
\end{tabular}
\end{center}

Thirteen units ordered by margin with \textbf{no inversions}, and the transition is a step rather
than a slope: between two points separated by $0.047$ of margin, \texttt{falsa\_abst} falls from
$0.2237$ to $0.0855$, a factor of $2.6\times$. In the band from $+0.1672$ to $+0.2358$,
\texttt{token} fails $4/4$ and \texttt{cabeza} passes $4/4$.

\paragraph{The operational number.} With a separate head it suffices to train to a margin of
$\approx +0.17$; with the vocabulary token one must reach $\approx +0.26$. \textbf{With $129$
parameters one can teach a model that recovers $10$ points worse to keep quiet.}

\paragraph{A confound, and the cell that resolved it.} Margin and degree of training are entangled
in the sampled range: all high-margin points came from truncated runs and all low-margin points from
complete ones. The missing cell is a model trained to completion that is nonetheless stuck at a low
margin. One seed failed to produce cuts and delivered exactly that cell---an easy-task run, trained
to completion, margin $+0.2124$---and a pre-registration froze two mutually exclusive predictions
before it was measured. \texttt{token} failed ($0.1885$) and \texttt{cabeza} passed ($0.0902$):
\textbf{the margin is not a proxy for task difficulty}. With a caveat we state rather than bury: the
binary verdict for \texttt{cabeza} rests on the final tick. What is robust is the paired contrast,
$7/7$ valid points in the same direction (sign test, $p = 0.0078$; means $0.2718$ vs.\ $0.1430$).

\subsection{The memory slot converges to the prior}
\label{sec:slot}

Two vectors are added to the archive, $k_{\varnothing}$ and $v_{\varnothing}$, competing as one more
column of the read. Following the design, the null is \emph{never} required to win the read---the
model demonstrably answers correctly with the right entry in second place---only to carry relative
mass. Three seeds, $26{,}000$ steps, paired against \texttt{cabeza} controls.

\begin{center}
\begin{tabular}{lccc}
\toprule
 & seed 0 & seed 1 & seed 2 \\
\midrule
accuracy (\texttt{cabeza} $\rightarrow$ \texttt{slot}) & $0.9705 \rightarrow 0.8991$ & $0.7769 \rightarrow 0.7859$ & $0.8351 \rightarrow 0.8999$ \\
\texttt{nose} (\texttt{cabeza} $\rightarrow$ \texttt{slot}) & $0.9119 \rightarrow \mathbf{0.0000}$ & $0.5416 \rightarrow \mathbf{0.0000}$ & $0.7298 \rightarrow \mathbf{0.0000}$ \\
\bottomrule
\end{tabular}
\end{center}

The model trains (the blocking sanity criterion passes $3/3$) and then never abstains, in any seed.
A clean zero is the signature of a broken instrument, and here it was one the first
time---an evaluation script tested \texttt{==} where it needed \texttt{in} and could not emit
abstention at all. The fix \emph{raises} accuracy in all three units ($0.7572 \to 0.8991$,
$0.4307 \to 0.7859$, $0.7744 \to 0.8999$), i.e.\ it favours the slot, and \texttt{nose} still reads
zero. A regression check reproduced every previously published unit bit for bit.

The mechanism is visible in the attention mass itself:

\begin{center}
\begin{tabular}{lccc}
\toprule
mass on the null slot & seed 0 & seed 1 & seed 2 \\
\midrule
questions \emph{with} an answer & $0.4074$ & $0.4046$ & $0.4020$ \\
questions \emph{without} an answer & $0.4086$ & $0.4065$ & $0.4037$ \\
AUC (without vs.\ with) & $0.5190$ & $0.5313$ & $0.5182$ \\
\midrule
\multicolumn{4}{c}{empirical base rate of unanswerable questions: $829/2048 = \mathbf{0.4048}$}\\
\bottomrule
\end{tabular}
\end{center}

\begin{quote}
\textbf{The slot learned the prior.} $0.4074 / 0.4046 / 0.4020$ against a base rate of $0.4048$ is
the exact optimum of the binary cross-entropy for a predictor with no usable signal. Because the
prior sits below any sensible decision threshold, ``it never abstains'' is not a badly chosen cutoff
but the \emph{necessary consequence} of having learned the base rate instead of membership.
\end{quote}

We tested the cutoff objection anyway, sweeping $400$ thresholds over the mass. No threshold passes
the gate in any seed; the best attainable point abstains on $\approx 80\%$ of unanswerable questions
and on $\approx 75\%$ of answerable ones (Youden's $J$ between $+0.038$ and $+0.078$, i.e.\ noise).
The two populations do not separate, so no cut can separate them.

\paragraph{Two observations worth recording.} First, a declared risk that did \emph{not}
materialize: the slot absorbs $\approx 40\%$ of the read mass on every query and accuracy holds at
$0.90 / 0.79 / 0.90$, with the superseded-value accuracy not degrading (and rising $+0.111$ in one
seed). The read tolerates losing four tenths of its mass to a constant vector. Second,
$v_{\varnothing}$ started at exactly zero and ended with norm $1.34$--$1.71$: the model did not use
it as a pure gate but learned a value for it, injecting a fixed vector into every answer---a learned
read bias, not a signal of absence.

\subsection{The result that frames the slot's failure}

The slot's negative is not an isolated disappointment. Independently and earlier, the archive's own
matching score---the maximum match of the query against the stored keys---separates ``the answer is
present'' from ``the answer is absent'' at $\mathrm{AUC}\ 0.4984$ and $0.5022$: chance to two
decimals. The top-2 margin and the logsumexp give the same. Three controls that could have failed
did not: logits reconstructed from the extracted score match the model's bit for bit, the score
varies, and the archive is used. Re-measured at the position of \emph{maximum focus}---where the
read concentrates up to $65\%$ of its mass on a single entry---it is still chance
($0.5007$, $0.5077$).

\begin{quote}
\textbf{The model selects an entry forcefully, and the force of the selection does not encode
whether what it was looking for is there. It always finds something, and it finds it with the same
conviction when there is nothing to find.}
\end{quote}

This is the expected consequence of the mechanism: a softmax read sums to one, so the best entry
wins with comparable mass whether or not a good candidate exists, and nothing in training ever
pressured the magnitude of the match to mean ``present''. \textbf{An external retriever gets the
empty set for free; moving the index inside the network destroys it}---and, as \S\ref{sec:slot}
shows, adding a place for absence to live does not restore it.

\section{What we do not claim}
\label{sec:noclaim}

Three restraints, stated because the results invite overreach.

\paragraph{This is calibration, not knowledge.} The supported claim is \emph{``separating the head
makes abstention learnable in this regime''}. The residual ceiling is one of calibration: the AUC of
the head's logit is $0.777$--$0.998$, so the information needed to decide is present---what is
misplaced is the cutoff. On the single unit that fails the gate, a threshold chosen on one half of
the data and judged on the other passes it. The sentence \emph{``the model knows when it does not
know''} is not supported by anything here.

\paragraph{Everything usable passes through labels.} Seven pre-registered attempts to obtain the cut
without supervision---a Gaussian mixture on the logit, an uncalibrated dispersion threshold, an
internal disagreement monitor under masking, a key-tie detector, and others---all landed in
$\mathrm{AUC}\ 0.50$--$0.67$, against $0.777$--$0.998$ for the supervised head. Two of them failed
for a reason worth reporting, because it constrains what a future detector must measure. In this
bench the model \textbf{never fabricates content}: out-of-archive answers occur at rate $0.0000$
across all four difficulty levels; every wrong answer is a real archived value attached to the wrong
entity. So when a question has no answer, the model does not guess into the void---it anchors on
\emph{another real entry}, and its answer is as stable under masking as a correct one. The
disagreement monitor confirmed the model reads the archive ($98$--$99\%$ of correct answers change
when the supporting entries are masked) and still could not discriminate, because
\textbf{disagreement measures whether the answer came from the archive, not whether it came from the
\emph{correct} entry}. Any future label-free detector has to separate those two things.

\paragraph{Hallucination here is misattribution, not invention.} The preceding paragraph has a
consequence for detection in general: in a model with an archive, the failure mode is a true value
placed on the wrong entity. That is \emph{harder} to catch than invention, because any verification
of the form ``does this datum exist?'' passes it. We flag the scope: with a closed vocabulary, free
fabrication is excluded by construction, so what is measured is that output stays confined to
archived content.

\section{Limitations}
\label{sec:limits}

\begin{itemize}
\item \textbf{Scale.} $863{,}730$ parameters and a synthetic $242$-token language. Nothing here
transfers automatically: \citet{cohen2024idk} works in large models and \emph{fails} at
pythia-70m/160m, which is precisely the asymmetry that makes small-model results non-predictive of
large ones. The direction of the transfer question is open in both directions.
\item \textbf{The language is the interface of the test, not the object of study.} A single-token
answer is what makes the metric exact without an LLM judge. No claim is made about open natural
language.
\item \textbf{Seeds and bimodality.} Bimodality across seeds is a measured property of this bench.
We report per unit and never as a mean alone; with two units in a cell, difficulty and
non-convergence cannot be separated. Two conditions have one seed per cell.
\item \textbf{The abstention-phase budget was chosen by the author}, and \S\ref{sec:presupuesto}
shows it mattered: one framing of the main result did not survive extending it. The paired
comparison at matched budget did.
\item \textbf{One implementation detail contradicts its own design}: the slot's decision threshold
was inherited as mass $> 0.5$, which is stricter than the design's own stipulation of relative mass.
The threshold sweep shows this does not explain the result, but it should be fixed if the condition
is revisited.
\item \textbf{Directed literature search, not a systematic review.} A work using different
vocabulary for the same idea---``rejection head'', ``versioned memory'', ``fact supersession''---may
have been missed.
\end{itemize}

\section{Conclusion}

Where the abstention decision lives changes whether it can be learned at all, and the ordering is
stable across seeds, budgets and margin regimes. A separate binary head costing $0.015\%$ of the
parameters halves to nearly thirds the false-abstention rate against a vocabulary token at matched
budget, and lowers by $\approx 0.10$ of accuracy margin the point at which a model becomes teachable
to keep quiet. The explanation is not the norm of the token's vector---the most generous version of
that hypothesis was implemented and failed---but the fact that two decisions of different natures
were competing for one softmax.

The memory slot, which on paper is the most elegant of the three because it makes ``nowhere'' an
expressible answer in the space where the model already operates, converges to the base rate and
never abstains. Together with an archive matching score pinned at chance, this locates a structural
property of co-trained memory: \textbf{absence has no representation there, and providing a place
for it is not enough to create one}. An external retriever can return the empty set; an internal
index read by softmax cannot, and the difference is not repaired by adding a null entry.

What remains open is the part that matters most and that none of these results reach: every route to
the decision that does not pass through labels has failed, and it has failed for a specific,
measured reason---the model, when it does not know, anchors on another real memory, which from the
outside is indistinguishable from knowing.
